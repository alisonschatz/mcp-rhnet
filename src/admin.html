Atualizar com um clique (favorito)

O servidor do RH Net não deixa este site ler a spec direto (CORS). O favorito resolve: ele roda na página do RH Net, lê a spec por lá e envia para cá.
  1. Arraste este botão para a barra de favoritos: ⟳ Atualizar MCP RH Net
  2. Para atualizar, clique no favorito (com a VPN ligada). Ele abre a spec do RH Net; clique no favorito de novo nessa página e pronto.
O favorito leva o seu token de acesso a esta tela: não compartilhe. Se trocar o ADMIN_TOKEN, arraste de novo.
